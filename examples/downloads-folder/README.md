# Example: downloads folder

This fictional folder demonstrates a shallow, preserve-first pass.

## Before

```text
downloads/
├── report-copy.pdf
├── draft-notes.md
├── image.png
└── unknown.bin
```

## Evidence

- `draft-notes.md` is clearly working material.
- `report-copy.pdf` may be a reference or duplicate; its authority is unknown.
- `image.png` has no safe semantic signal beyond its file type.
- `unknown.bin` is not opened without a reason and safe capability.

## Safe plan

Propose only a working folder for `draft-notes.md`. Leave the other items in place until content, ownership, or duplicate evidence is available. Do not delete `report-copy.pdf` merely because its name contains “copy”.
